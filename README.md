# Automação ITI

Aplicação em Python para extrair os dados de certificados mensais por região do portal Números ITI e gerar um relatório em Excel.

## Funcionalidades

- Download automático dos dados do ITI
- Extração dos certificados mensais por região
- Geração de relatório Excel
- Interface gráfica com CustomTkinter

## Executar o projeto

```powershell
python main.py
